# movie_template

HTML, CSS, JavaScript를 활용하여 영화 정보를 화면에 구성한
영화 페이지 제작 예제 프로젝트입니다.

## 📌 프로젝트 소개

영화 정보를 카드 형태로 구성하고 JavaScript를 이용하여
영화 데이터를 동적으로 화면에 출력하는 페이지를 제작했습니다.

HTML과 CSS를 이용한 화면 구성뿐만 아니라 JavaScript를 활용한
동적 콘텐츠 생성 과정을 학습하는 것을 목표로 했습니다.

## 🛠️ 기술 스택

- HTML
- CSS
- JavaScript

## ✨ 주요 기능

- 영화 목록 출력
- 영화 포스터 및 정보 표시
- JavaScript를 이용한 영화 데이터 동적 생성
- 영화 정보 카드 UI 구성
- 사용자 이벤트 처리

## 📚 학습 내용

- JavaScript 객체와 배열을 이용한 데이터 관리
- 반복문을 이용한 데이터 출력
- DOM API를 이용한 요소 생성
- `innerHTML`을 이용한 HTML 콘텐츠 구성
- 이미지 경로 및 HTML 요소 처리
- CSS를 이용한 카드 형태의 UI 구성

## 📝 느낀 점

정적인 HTML을 작성하는 방식에서 벗어나 JavaScript 데이터를 기반으로
화면의 콘텐츠를 동적으로 구성하는 방법을 학습했습니다.

영화 정보와 같은 반복적인 데이터를 JavaScript로 관리하면
HTML 코드를 반복해서 작성하지 않고도 여러 콘텐츠를 구성할 수 있다는 점을
이해할 수 있었습니다.
